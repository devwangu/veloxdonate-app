Cloudflare Mode

⚪ ไม่ได้เลือกใช้งาน

ใช้งานได้ฟรีโดยไม่ต้องสมัครสมาชิก VeloxGG แต่ว่าลิงก์ของคุณก็จะสุ่มใหม่ทุกครั้งที่เปิดโปรแกรมใหม่ (ต้องแปะลิงก์ Donate ใหม่ทุกครั้ง)

🔗 ลิงก์สุ่มปัจจุบัน:
ปลอดภัยสูงด้วย HTTPS Encryption + Cloudflare Anti-DDoS Protection ค่าบริการ: ฟรี 100%

VeloxGG Mode ⭐ (แนะนำ)

🟢 กำลังใช้งานอยู่ (Active)

ได้ลิงก์คงที่ไม่เปลี่ยนใหม่ทุกครั้งที่เปิดปิดโปรแกรม (สบายกว่า Cloudflare Mode ไม่ต้องแปะลิงก์ใหม่)

* ล็อกอินเว็บ donate.veloxgg.com ไปที่ Dashboard เพื่อคัดลอก Token ประจำบัญชีของคุณ
กำลังตรวจสอบสถานะการเชื่อมต่อ...
Cloudflare Reverse Proxy Shield ระบบป้องกัน Hi-End จาก Cloudflare ค่าบริการ: ฟรี 100% สำหรับสตรีมเมอร์ทุกคน

Custom Domain Mode

🔒 บริการต่อตรงโดเมนส่วนตัว (เปิดบริการเร็วๆ นี้)

ใช้ชื่อโดเมนส่วนตัวของสตรีมเมอร์มาผูกกับระบบ โดยทีมงาน VeloxGG เป็นผู้ช่วยดำเนินการจดและดูแลโดเมนให้โดยตรง

ทีมงานจดโดเมนและตั้งค่า HTTPS ให้อัตโนมัติ ค่าบริการ: จ่ายเฉพาะค่าจดโดเมนตามจริง (ไม่มีค่าบริการระบบเพิ่มเติม)

สร้างสูตรอัตโนมัติ

คู่มือย่อลิงก์สร้างชื่อรับโดเนทสวยๆ ด้วย TinyURL

ลิงก์สาธารณะ Cloudflare Quick Tunnel (เช่น xxx.trycloudflare.com) มีความปลอดภัยและฟรี 100% แต่ชื่อ URL อาจดูสุ่มและจำยาก คุณสามารถย่อลิงก์ให้เป็นชื่อช่องของคุณเองได้ง่ายๆ ฟรี 100% ไม่เสียค่าใช้จ่าย เช่น tinyurl.com/SAIBOK-Donate ด้วยขั้นตอนดังนี้:

1
คัดลอกลิงก์รับโดเนทสาธารณะ Cloudflare สามารถกดปุ่มคัดลอกลิงก์ได้ทันทีตรงนี้ หรือกดผ่านการ์ดลิงก์สาธารณะในหน้าหลัก Controller
2
เปิดเว็บย่อลิงก์ TinyURL.com กดเปิดเว็บไซต์ย่อลิงก์ฟรีผ่านปุ่มด้านล่างนี้
เปิดเว็บ TinyURL.com
3
วางลิงก์และตั้งชื่อสตรีมเมอร์สั้นๆ (Custom Alias) วาง URL ในช่อง Enter long URL แล้วตั้งชื่อสั้นๆ ในช่อง Customize your link (Alias) เช่น SAIBOK-Donate
4
เสร็จสิ้น! ได้ลิงก์รับโดเนทสวยงามพร้อมแปะหน้าสตรีม คุณจะได้ลิงก์ เช่น https://tinyurl.com/SAIBOK-Donate ไปใส่ในช่องคำอธิบายไลฟ์หรือแปะปุ่มโดเนทได้ทันที!
